# BabyCry AI — free PWA prototype

A bilingual (Persian/English) installable web app for iPhone. Includes microphone recording (max 15 seconds), baby profile, offline cache, and local IndexedDB recording history. No AI diagnosis or model is included. Audio never leaves the browser.

## Free deployment via GitHub Pages
1. Create a GitHub repository (public for free GitHub Pages on GitHub Free).
2. Upload the contents of this folder to the repository root.
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
4. Wait for the Pages URL, usually https://USERNAME.github.io/REPO/.
5. Open that URL on iPhone Safari. Share > Add to Home Screen > Add.
6. Allow microphone when prompted. HTTPS is required for recording.

Note: Public GitHub repository exposes source code, not recordings. Recordings stay in local browser storage. Clear history before sharing a device. iOS may evict local browser storage; recordings are not backed up.

Not a medical device. If a baby under 3 months has fever >=38°C or breathing problems, lethargy or unusual inconsolable crying, seek urgent medical advice.
